# NTU Mailer 使用教學

這份教學說明如何準備收件人 CSV 檔案，以及如何設定寄件帳號。

## 一、下載並填寫收件人 CSV

1. 在網頁介面「2. 收件人清單」區塊，點擊「下載範例 CSV」
2. 用 Excel 或記事本開啟後，依照以下欄位填寫：

| 欄位 | 是否必填 | 說明 |
|---|---|---|
| `email` | 必填 | 收件人信箱。**若對方是台大信箱，可以只填學號，不用打 `@ntu.edu.tw`** |
| `name` | 選填 | 收件人姓名，內文可用 `$name` 替換 |
| `cc` | 選填 | 副本信箱，多筆用空格分隔 |
| `bcc` | 選填 | 密件副本信箱，多筆用空格分隔 |

![CSV 填寫範例示意圖](images/csv-example-placeholder.png)
*（此處放置 CSV 在 Excel 中的填寫範例截圖）*

3. 存檔時請選擇「CSV（逗號分隔）」格式，副檔名為 `.csv`

### 新增自訂欄位，客製化信件內容

除了上面幾個固定欄位，你可以在 CSV 裡自由新增任何欄位，並在信件內文中用 `$欄位名` 替換成每位收件人專屬的內容。

**做法：**

1. 在 CSV 新增一欄，例如 `department`（系級）、`event`（活動名稱），欄位名稱建議用英文、不要有空格
2. 在信件內文中用 `$欄位名` 標記要替換的位置
3. 寄送時系統會自動把每一列對應的值填進去，每個收件人看到的內容都不同

**範例：**

CSV：
```
name,email,cc,bcc,department,event
王小明,B12345678,,,農藝三,迎新茶會
陳小華,B98765432,,,園藝二,迎新茶會
```

內文：
```html
<p>親愛的 $name 您好，</p>
<p>您是 $department 的學生，誠摯邀請您參加本次 $event。</p>
```

寄給王小明的信會自動變成：
> 親愛的 王小明 您好，
> 您是 農藝三 的學生，誠摯邀請您參加本次 迎新茶會。

**注意事項：**

- 欄位名稱不能是 `email`、`cc`、`bcc`，這三個是系統保留欄位，無法用於文字替換
- 若內文寫了 `$欄位名`，但 CSV 沒有這個欄位或該列資料是空的，系統不會報錯，只會原樣保留 `$欄位名` 這串文字，不會中斷整批寄送
- 欄位名稱區分大小寫，`$Name` 和 `$name` 會被當成不同的東西，請確保 CSV 欄位名稱與內文中使用的完全一致

## 二、設定寄件帳號

### 使用台大信箱寄送

1. 確認網頁上方的 Gmail 開關是**關閉**狀態
2. 「台大學號」欄位只需輸入學號本身，例如 `B12345678`，不要加 `@ntu.edu.tw`

![台大信箱帳號設定示意圖](images/ntu-account-placeholder.png)
*（此處放置台大信箱設定區塊的截圖）*

> **重要提醒**：台大信箱寄信伺服器僅允許校內網路連線。若你不在校園網路，請先連上台大 VPN 或校內網路（ntu_peap, eduroam）再寄信，否則會出現連線逾時的錯誤。

### 使用 Gmail 寄送

1. 打開網頁上方的 Gmail 開關
2. 需先在 Google 帳戶開啟兩步驟驗證，並產生「應用程式密碼」（不是一般登入密碼）
3. 「Gmail 完整信箱地址」欄位填完整信箱，例如 `yourname@gmail.com`

![Gmail 應用程式密碼設定示意圖](images/gmail-app-password-placeholder.png)
*（此處放置 Google 帳戶產生應用程式密碼的步驟截圖）*

## 三、寄送流程

1. 上傳填好的 CSV
2. 填寫信件主旨與內文
3. **務必先按「測試寄送」**，確認格式、內文變數替換、附件都正確
4. 確認無誤後，勾選確認框，按「正式寄送」
5. 寄送完成後，畫面會提供寄件記錄檔案供下載，可保留作為備份
